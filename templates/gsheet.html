🔧 Setup Guide (Pertama Kali)
  1. Google Cloud Console → APIs & Services → Enable Google Sheets API + Google Drive API
  2. Buat Service Account → Download JSON key → Simpan sebagai credentials.json di folder project
  3. Buat Google Spreadsheet baru (kosong) → Share ke email service account
    Email format: xxx@xxx.iam.gserviceaccount.com (lihat di file credentials.json → client_email)
  4. Copy Spreadsheet ID dari URL: 
    https://docs.google.com/spreadsheets/d/{SPREADSHEET_ID}/edit
  5. Set environment variables: 
    export GOOGLE_CREDENTIALS="credentials.json"
export GOOGLE_SPREADSHEET_ID="your-spreadsheet-id-here"
  6. Klik tombol "🚀 Setup Sekarang" di atas → Spreadsheet langsung siap pakai!

🏢 Multi-Division Setup (Advanced)

Kalau setiap divisi punya spreadsheet terpisah (untuk privasi), gunakan IMPORTRANGE di Master Sheet: 

// Di Master Sheet tab "Raw Data", tarik dari sheet tiap divisi:
={
  IMPORTRANGE("SPREADSHEET_ID_SALES", "Transactions!A2:F");
  IMPORTRANGE("SPREADSHEET_ID_MARKETING", "Transactions!A2:F");
  IMPORTRANGE("SPREADSHEET_ID_IT", "Transactions!A2:F")
}
// Klik "Allow Access" sekali per link

Tips: Pastikan setiap divisi sheet punya format kolom yang sama (Date | Division | Category | Description | Amount | Status). Gunakan tombol "Setup" di atas untuk setiap sheet divisi supaya format-nya konsisten.
