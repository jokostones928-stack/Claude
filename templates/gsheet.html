Langkah Setup:
  1. Buka Google Cloud Console → APIs & Services
  2. Enable Google Sheets API dan Google Drive API
  3. Buat Service Account → Download JSON key
  4. Simpan file JSON sebagai credentials.json di folder project
  5. Buat Google Spreadsheet baru, lalu Share ke email service account
  6. Set environment variable: 
    export GOOGLE_CREDENTIALS="credentials.json"
export GOOGLE_SPREADSHEET_ID="your-spreadsheet-id-here"
